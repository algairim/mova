## Transcription

Every Ukrainian expression is followed by its pronunciation in `code style`, written for an English reader.

| Letter | Written | Sounds like |
|---|---|---|
| а | `a` | a in *father* |
| б | `b` | b |
| в | `v` | v (at the end of a word closer to w) |
| г | `h` | h in *hand*, but voiced |
| ґ | `g` | g in *go* |
| д | `d` | d |
| е | `e` | e in *bed* |
| є | `ye` | ye in *yes* |
| ж | `zh` | s in *vision* |
| з | `z` | z |
| и | `y` | i in *bit* |
| і | `i` | ee in *see* |
| ї | `yi` | yea in *yeast* |
| й | `y` | y in *boy* |
| к | `k` | k |
| л | `l` | l |
| м | `m` | m |
| н | `n` | n |
| о | `o` | o in *more*, never reduced to *uh* |
| п | `p` | p |
| р | `r` | rolled r |
| с | `s` | s in *sun* |
| т | `t` | t |
| у | `u` | oo in *boot* |
| ф | `f` | f |
| х | `kh` | ch in Scottish *loch* |
| ц | `ts` | ts in *cats* |
| ч | `ch` | ch in *church* |
| ш | `sh` | sh in *shoe* |
| щ | `shch` | sh-ch, as in *fresh cheese* |
| ь | `'` | no sound of its own: the consonant before it is softened, as the n in *onion* |
| ю | `yu` | you |
| я | `ya` | ya in *yard* |
| ’ | — | the apostrophe of Ukrainian spelling is not written; the `y` after it is a separate glide |

Letters are written one after the other as they are pronounced, with one exception: зг is written `zgh` (`zghóden`), so that it is not read as ж.

An acute accent marks the stressed vowel of every word of two syllables or more (`dóbryy den'`). Words of one syllable carry no mark. Ukrainian stress is free and can fall on any syllable, so it has to be learned with the word.
